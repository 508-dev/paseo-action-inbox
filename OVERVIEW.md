# Action inbox

See pending agent questions, tool approvals, failed runs, and finished work needing review across your online Paseo hosts. Open the owning agent from any card. Small tool approval requests show direct provider actions after a fresh pending-request check.

Requires Paseo 0.16.0-beta.1 or newer on the daemon and app. Install the plugin on one connected host; its client screen reads the app's existing connections to other hosts. It refreshes every 20 seconds while open and reads up to 1,000 active agents per host.

Structured questions and long or non-tool permission requests open in Paseo's native agent view. The inbox does not show stale offline-host state, clear attention, or resume failed runs.
